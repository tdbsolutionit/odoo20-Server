TDB Custom PLM

Omnia CAD connectivity, live PLM views and level-based review and redo tasks.

Select one higher-level reviewer. Level 2 approves and submits to a selected Level 3 reviewer in one confirmation. Level 3 can confirm and release directly. Rejection creates a redo activity for the reviewer or a lower-level worker; delegated work returns through its assignment chain.

Decisions, returns and direct admin confirmations are recorded in Chatter and structured history. Activity completion alone does not grant approval; permissions and task ownership are enforced on the server.
